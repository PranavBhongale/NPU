## Current Design Phase

I am currently working on the **architectural and microarchitectural design decisions** for this NPU.

This phase may take approximately **one month**, as the goal is to carefully evaluate and finalize the key design choices before beginning the main RTL implementation.

Precise design decisions at this stage will make the project **technically viable, consistent, and easier to implement and verify** in the later stages.

The current focus includes:

- NPU architecture and overall organization
- Dataflow and computation model
- Processing element (PE) architecture
- MAC and arithmetic architecture
- Memory hierarchy and data movement
- On-chip buffers and bandwidth requirements
- Quantization and numerical representation
- Control and scheduling mechanisms
- Interface and communication architecture
- Performance, area, and power considerations
- Verification strategy

The objective is to establish a **well-defined microarchitecture and design specification** before committing to the final RTL implementation.
